# pizzaria-python-management
Sistema de vendas para pizzaria em Python que une lógica de programação à minha experiência como ex-dona de lanchonete e RH. Inclui precificação dinâmica com dicionários, validação de dados e foco na experiência do colaborador e do cliente. Projeto acadêmico de Ciência da Computação focado em soluções reais de negócio.
